What You Get

A complete training and analysis flow inside one native app.

Adjustable Strength

Set bot strength with an Elo slider from 600 to 2800 so you can spar, test lines, or push max depth.

Opening + Phase Detection

The sidebar tracks opening, middlegame, and endgame labels in real time while the move list grows.

Chess.com-style Arrows

Draw analysis arrows directly on the board. Use right-drag to place them, then clear instantly with Esc or left click.

Copy State / Copy Game

Export any moment with Copy State (FEN) or copy the full game with Copy Game (PGN with algebraic notation).

Search Prism Telemetry

Watch depth, nodes, NPS, eval trend, volatility, and candidate move gaps update live as the engine searches.

Insane Theme Library

Cycle through a huge palette catalog with generated variants, from clean tournament looks to bold, cinematic boards.

Practical Insight

Not just pretty charts. Useful match context.

Chessplate exposes enough signal to understand why the bot prefers one move over another. You can see stability, volatility, and lead gap while still keeping the board front and center.

  • Top candidate lines shown with centipawn score and relative confidence bars.
  • Depth and node speed visible during calculation, not after the move is played.
  • Move history recorded in SAN so you can read games naturally.

Phase Lens

Instant labels for opening, middlegame, and endgame keep training goals focused per stage.

Rapid Reset

Switch sides, restart fast, and keep iterating positions without workflow friction.

Local-First

No account, no queue, no network lag. Launch and play directly on your machine.

Theme Playground

Sample the style system. The app ships with dozens more.

Tap any swatch to recolor this site preview. The desktop app includes a larger generated catalog with 90 themes.

Get Started

Run Chessplate in minutes.

Build and run the native app from source:

cargo run --release

1. Launch

Start the app and pick a theme + Elo that matches your training goal.

2. Play + Analyze

Use arrows and Search Prism to investigate tactical ideas mid-game.

3. Export

Copy FEN/PGN and carry positions into your study workflow.
